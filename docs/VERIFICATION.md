## HTTP 烟雾测试内容

脚本创建两笔虚构交易并保留供查看：第一笔完成四级审批至 APPROVED/version=5；第二笔驳回后完整字段重提至 PENDING_L1/version=3。另验证跨申请人访问 403、跨部门审批 403、旧版本重复审批 409。它可对使用 MySQL 的本地后端重复运行，每次创建新的数据。

浏览器测试额外创建一笔申请并完成四级审批，验证页面、代理、请求头、金额字符串传输、身份切换、详情状态及审批记录相互衔接。
